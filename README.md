# Calculadora

- Descripcion: 
Este proyecto se trata de una sencilla calculadora aritmetica con la cual al introducir dos numeros se podran sumar, restar, multiplicar, dividir...

## Instrucciones de instalacion
1. Copiar enlace del repo: 
    Para ello, deberás ir al apartado de `code` en este apartado del repositorio y copiar el enlace http o ssh, depende de como lo prefieras.

2. Clonacion del repositorio: 
    Una vez estes en la carpeta en la cual se va a alojar nuestro programa abres una terminal y ejecutas el siguiente comando: 

    ```git
        git clone <enlace>
    ```


## Instrucciones de uso

Tras tener el repositorio clonado: 
1. deberas ir a src> app.js y abrir otra terminal: 

```bash
    cd /tu-directorio/src/app.js
    node app.js #esto te permitirá ejecutar el programa sin necesidad de tener un servidor web
```

2. Para realizar una operación bastará con elegir una opcion del menu de opciones entre el 1 y el 5. Tras ello deberás introducir los digitos con los cuales se va a realizar la operacion y posteriormente se mostrará el resultado.
